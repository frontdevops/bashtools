# bashtools

Shell utilities for server maintenance. Each directory has its own usage guide.

| Directory | Utilities |
| --- | --- |
| [cron](cron/README.md) | Create cron jobs and manage per-environment crontabs. |
| [mongo](mongo/README.md) | Export MongoDB databases, download production backups, and restore archives. |

## Get the tools

```bash
git clone https://github.com/frontdevops/bashtools.git
```

See each directory's README for requirements, configuration, and examples.
